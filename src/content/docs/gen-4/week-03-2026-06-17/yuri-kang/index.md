## 한 줄 요약

> 미국-이란 전쟁의 충격이 예상보다 작았던 비결은 **'고압경제'**라는 강한 부양 처방. 하지만 진짜 쟁점은 전후 처리가 아니라, **AI 시대에 무기력해진 통화정책 프레임워크와 흔들리는 달러 체제를 어떻게 다시 짤 것인가**다.

## 0. '자본주의 4.0'이 뭔가

- 거칠게 보면: **1.0 자유방임(작은 정부)** → **2.0 케인스식 큰 정부(복지국가)** → **3.0 신자유주의(시장 만능)** → **4.0 정부·시장 협력형 새 모델**.
- 기사의 메시지: 전쟁·AI 충격 앞에서 전통 정책이 한계 → '제3의 정책'·새 프레임워크 필요 = "자본주의 4.0으로 넘어가는가".

> (참고) '자본주의 4.0'은 경제평론가 **아나톨 칼레츠키**가 2008년 금융위기 후 제시한 개념. 기사는 이 틀을 빌려 '포스트-워 + AI 시대의 새 경제 운영방식'을 묻는다.

## 1. 미국-이란 전쟁, 왜 예상보다 충격이 작았나

- **2026년 2월 28일 전쟁 발발.** 당시 지배적 전망은 스태그플레이션 우려 + 글로벌 증시 큰 폭 조정.
- 실제 결과는 정반대:

| 경제 | 결과 |
| --- | --- |
| 미국 | 잠재성장률 **웃돔** |
| 중국 | 목표치 **달성** |
| 한국 | 높은 수준 기록, 코스피·글로벌 주가 **전쟁 이전 수준 돌파** |

- 한상춘 위원이 꼽은 원인 두 가지: ① **뉴노멀**(금융과 실물의 인과관계가 뒤바뀐 여건) ② **고압경제(HPE)**.
- '주가 따로 노는' 수수께끼: 보통은 전쟁→실물 타격→주가 하락인데 이번엔 주가가 올랐다. 한 위원은 **"주가가 오르면 자산 효과가 생겨 전쟁이 실물에 주는 충격을 완충한다"**고 설명.

> (개념) **자산 효과(wealth effect)**: 주식·부동산 등 보유 자산 가치가 오르면 '부자가 된 느낌'에 소비·투자를 늘리는 현상.

## 2. 핵심 개념 — '고압경제(HPE)'

- 재정+금융 완화로 노동시장에 **초과 수요**를 만들면:
  - 임금 상승 → 자발적·비자발적 실업자 모두 고용시장 복귀
  - 기업: 예상 수익 증가 → 설비투자 확대
  - **정부 지출 + 민간 소비 + 설비투자 동시 증가 → 전체 성장률 크게 상승**

### 이론적 배경 — '예일 거시경제 패러다임'

| 과제 | 처방 이론 |
| --- | --- |
| 단기 과제 | **케인지언 이론** (수요 부양) |
| 장기·지속가능 성장 | **토빈 + 로버트 솔로 모델** (자본·기술 축적) |

- 정책 조합: 재정은 **건전화 틀 유지**, 통화는 **적극 운용**, 그리고 **물적자본·인적자본·R&D에 지속 투자**.
- 한 위원: "이 패러다임이 **1960·1990년대 미국 장기 호황**을 이끌었고 **아베노믹스**에도 영향을 미쳤다."

## 3. 전쟁의 첫 후유증 — 재정 파탄 우려

- **트럼프 정부 + 일본 다카이치 정부**의 인식 = 피케티 공식: **g > r 이면** 빚을 더 써도 재정적자·국가부도 걱정 없다.
- 한 위원의 경고: "국가채무비율이 높은데 세출↑·세수↓면 디폴트 우려가 커진다. **재정적자→포퓰리즘→더 큰 재정적자** 악순환에 빠질 수 있다."
- 제언: 전통적 재정·통화가 아닌 **제3의 정책** + **더 강력한 친(親)증시 정책**. 일본처럼 저량·유량 변수 모두에 성장 장애가 있으면, 긴축이든 부양이든 **반짝 효과만 나는 '캠플 주사'**에 그칠 위험이 크기 때문.

> (개념) **피케티의 r vs g**: 자본수익률(r)이 성장률(g)보다 높으면 불평등이 커진다는 맥락에서 유명하지만, 여기서는 **'성장률이 이자율보다 높으면 빚 부담이 줄어든다'**는 재정 논리로 쓰임.
> **저량(stock) vs 유량(flow)**: 저량은 한 시점의 누적량(부채 총액 등), 유량은 일정 기간의 흐름(소득·투자 등). 둘 다 문제면 일시 처방으론 안 된다는 뜻.

## 4. 본론 — 전쟁 이후 통화정책 프레임워크의 대전환

### 중앙은행 수장 교체

| 중앙은행 | 새 체제 |
| --- | --- |
| 한국은행 | **신현송** 체제 |
| 미국 Fed | **케빈 워시** 체제 |
| ECB | 새 체제 출범 임박 |

### 직면한 6가지 쟁점

1. **물가안정 vs 고용창출(Fed 양대 목표 수정론)** — 필립스 관계(실업↔물가)와 베버리지 관계(실업↔구인율)가 동시에 흐트러진 상황. 경기 후행 지표인 고용을 보고 금리를 바꾸면 **선제성**을 잃는다. 통화론자는 "고용은 떼고 **물가안정만 우선**" 주장.
2. **선제성 = 통화준칙의 생명** — **평균물가목표제(AIT)**가 물가를 키워놓고 **뒤늦게 금리를 올리는** 과정에서 **'현상 유지의 폭정'**을 낳았다는 비판.
3. **통화정책 수단 개편** — 경기순환주기가 짧아지는데 **시차가 긴 기준금리**로는 목표 달성 어려움. 최종 목표와 연계성 높은 **표적변수**로 점검하고, 연방기금금리도 **on RRP**로 대체할 때.
4. **목표 달성 가능성 자체** — **케인지언 전달경로가 작동 안 함** → 총수요 영향 미미. 공개시장조작·재정과 협조해 **시장금리를 직접 조절**하자.
5. **'투명성의 역설'** — 모든 걸 공개하는 게 오히려 **시장에 주도권을 빼앗기는** 결과를 낳을 수 있다.
6. **법칙의 무력화** — 실업률 상승이 일시적 병목·불일치 때문이라면 기존 법칙(삼의 법칙 등)이 안 맞고, **AI 시대엔 무력화**될 수 있다.

### 한 위원의 진단과 시사점

- **한 위원의 진단**: "중앙은행 목표를 물가안정에만 둘 수 없고, 기준금리·유동성 조절 같은 종전 수단도 효과가 반감될 수 있다."
- **케빈 워시 Fed 의장의 입장**: Fed **독립성**을 스스로 지켜야 하며, **양대 책무는 물가안정으로 회귀**해야 한다.
- 시사점: 워시 체제에서 **Fed 프레임워크가 크게 바뀔 수 있는 만큼**, 한국은행·금융사·투자자도 우리 통화정책·금융시장에 미칠 영향을 주목해야.

## 5. 인터뷰 박스 — 원·달러 환율의 미래는

### (1) 전쟁 종료 후 달러 체제 변화, 한국 영향은

- 원화 가치를 **머큐리 요인 + 마스 요인**으로 나눠보면 **한국 펀더멘털은 건전**.
  - 1분기 성장률 **연율 7% 근접**, 경상흑자 **737억 달러**.
  - 올해 전체 성장률 **2.5% 내외**(미국 2% 내외보다 높음).
- 정책 의도는 분명히 **원·달러 환율 하락(원화 강세)** 쪽: 7월부터 본격화될 **대미 투자재원** 마련 위해. 작년 12월부터 **외환시장 개입**. 대통령도 **1400원 밑** 목표.
- **적정 환율**: 실질실효환율 기준 **1350원 내외**. 현재는 적정 대비 **150원 이상 높은(원화 약세) 상태**.

> (개념) **머큐리 vs 마스 요인**: 환율을 움직이는 두 힘. 머큐리=펀더멘털(성장·경상수지 등), 마스=정책·지정학 같은 인위적 요인. (전략가 데이비드 로시의 분류)

### (2) 달러 폭망론 vs 킹달러론

- **킹(king) 달러 시대**는 정작 **미국부터 원하지 않는다**.
- 두 극단으로 환율을 그리면: 폭망론→**1000원대**, 킹달러론→**2000원대**.
- 한 위원 판단: 브레턴우즈 체제 변천사를 보면 **양 극단보다 중간 지대**, 다만 **폭망론(전자) 쪽 확률이 더 높다** → **원·달러는 올해 정점 후 점차 1400원 밑 안정** 전망.

### (3) 한국의 대처

- 정부가 지난 1년간 추진: NPS와 **650억 달러 통화스와프·환헤지** 협의 / 증권사 환전 관리 점검 / 기업 달러 보유분 페널티 / 해외주식 양도세 강화(리플럭스 시 면제) / **MSCI 선진국 지위** TF.
- 한 위원 당부: 어려울수록 **스틸스 달러라이제이션 자제**. 기업은 환율 **'수준'보다 '변동성' 관리**에. 한쪽에 치우친 베팅은 큰 손실 위험 → **선물환·환변동 보험**으로 환위험 관리.

> (개념) **스틸스 달러라이제이션**: 공식적으론 자국통화를 쓰지만 기업·개인이 슬그머니 달러 보유·거래를 늘려 경제가 달러에 잠식되는 현상.

## 용어 사전 (한눈에)

| 용어 | 쉬운 설명 |
| --- | --- |
| **고압경제(HPE)** | 경제를 일부러 '약간 과열' 상태로 강하게 밀어붙이는 부양책. 수요를 초과 상태까지 끌어올려 일자리·투자를 빡빡하게 만든다. 경제학자 아서 오쿤이 제시. |
| **스태그플레이션** | 'Stagnation(경기침체) + Inflation(물가상승)'의 합성어. 경기는 나쁜데 물가는 오르는 최악의 조합. 금리를 올리자니 경기가 죽고, 내리자니 물가가 뛰어 중앙은행이 가장 곤란해함. |
| **예일 거시경제 패러다임** | 예일대 계열(토빈 등)의 거시경제 운영 틀. **단기는 케인스식 부양 + 장기는 자본·기술 축적**을 병행하고, 재정은 건전하게·통화는 적극적으로 쓰며 R&D 투자를 강조. 고압경제의 이론적 뿌리. |
| **케인지언 이론** | 케인스 계열. **"불황엔 정부가 돈을 풀어 수요를 만들어야 경제가 산다"**는 입장. 정부 지출·감세로 단기 경기를 떠받치는 것을 중시. (통화론자와 대비) |
| **토빈 · 로버트 솔로 모델** | 둘 다 노벨상 경제학자. **토빈**=자산·투자 이론(자본을 어떻게 굴릴지), **솔로**=장기 성장은 결국 **자본·노동·기술 축적**에서 나온다는 성장 모델. 기사에선 '장기 과제(지속 성장)' 처방으로 인용. |
| **재정적자–포퓰리즘 (악순환)** | 표(인기)를 얻으려 세금은 깎고 지출은 늘리면(포퓰리즘) → 나라 빚(재정적자)이 쌓이고 → 다시 인심성 지출로 메우려다 → 빚이 더 커지는 **돌고 도는 악순환**. |
| **저량(stock) vs 유량(flow)** | **저량**=한 '시점'에 쌓여 있는 양(예: 부채 잔액, 통장 잔고). **유량**=일정 '기간'에 흐른 양(예: 소득, 투자). 둘 다 나쁘면(빚도 많고 소득도 안 늚) 일시 처방으론 못 고친다. |
| **캠플(캠퍼) 주사** | 응급 강심제 주사. **잠깐 기운 차리게 할 뿐 근본 치료는 안 되는 임시방편**을 비유. 기사에선 "긴축이든 부양이든 반짝 효과만 나는" 정책을 가리킴. |
| **역(逆)의 필립스 관계** | "실업률이 낮아지면(고용 good) → 물가가 오른다"는 **반대 방향 관계**. 고용과 물가가 시소처럼 움직인다는 고전 가정. 요즘은 이 관계가 깨져서 통화정책의 기준이 흔들림. |
| **평균물가목표제(AIT)** | 2020년 Fed 도입. 한동안 물가가 목표(2%)보다 낮았으면 **나중에 좀 넘쳐도 봐주고 '평균'을 맞추는** 방식. 단점: 물가가 올라도 금리 인상을 미루다 뒤늦게 급히 올리게 됨('현상 유지의 폭정' 비판). |
| **on RRP (익일물 역레포)** | Fed가 시중 자금을 하루 흡수하며 **단기 시장금리의 바닥(하한)**을 잡는 도구. 기사 맥락: "느린 기준금리 대신 시장금리를 더 직접 조절하는 수단으로 갈아타자". (세부 기계적 원리는 발표에서 깊이 안 들어가도 됨) |
| **삼의 법칙 (Sahm Rule)** | ※본문 '삶의 법칙'은 오독. 경제학자 클라우디아 삼이 만든 **경기침체 판별 규칙**: 실업률(3개월 평균)이 최근 1년 최저점보다 0.5%p 오르면 '침체 시작' 신호. 기사: AI 시대엔 실업률 상승이 일시적 병목 탓일 수 있어 **이 법칙이 안 맞을 수 있다**. |
| **머큐리 요인 / 마스 요인** | 환율을 움직이는 두 힘(전략가 데이비드 로시 분류). **머큐리**=경제 기초체력(성장·경상수지 등 펀더멘털), **마스**=정책·지정학 같은 인위적·전투적 요인. |
| **킹달러론** | "달러가 제왕처럼 초강세가 될 것"이란 전망(→ 원·달러 2000원대 시각). 기사는 "정작 미국부터 원하지 않는다"며 가능성을 낮게 봄. (반대편이 '달러 폭망론' = 원·달러 1000원대) |
| **스틸스 달러라이제이션** | 공식 통화는 원화인데, 기업·개인이 **슬그머니 달러 보유·거래를 늘려** 경제가 달러에 잠식되는 현상('stealth'=몰래). 환율 불안 때 심해지며, 한 위원은 "어려울수록 자제하라"고 당부. |
| **리플럭스(reflux)** | '되돌아옴·환류'. 여기선 **해외에 나가 있던 투자 자금을 국내로 다시 들여오는 것**(자본 회수). 정부가 "리플럭스(국내 회수) 때는 양도세를 면제"해 자금이 들어오도록 유도. |
